# Chrome Web Store listing copy (English)

Use this text in the [Chrome Web Store Developer Dashboard](https://chrome.google.com/webstore/devconsole).

## Extension name

`BIDI - Forge`

## Short description (max ~132 characters)

Fix mixed Persian, Arabic & English text in AI chats (Claude, ChatGPT, Gemini, Grok) with Unicode BiDi — local only.

## Detailed description

**BIDI - Forge** improves readability when right-to-left languages (Persian, Arabic) are mixed with English, numbers, URLs, code, and punctuation.

Many AI chat UIs (Claude, ChatGPT, Gemini, Grok, Qwen, Copilot, Perplexity, and more) show broken word order, mirrored parentheses, or scrambled paths like `/(marketing)/about` in Persian replies. **BIDI - Forge** inserts standard Unicode bidirectional marks (LRM, RLM, isolates) and applies safe CSS hints (`dir=auto`, `unicode-bidi: plaintext`) where needed.

### Features

- **Claude-first** — composer + streaming assistant replies
- **ChatGPT, Gemini, Grok** — CSS-only composer path (no marker spam while typing)
- Fix mixed RTL/LTR text in page content and chat composers
- **AI chat sites only** mode (built-in presets + extra hosts) or all websites
- Exclude specific hostnames you never want touched
- Enable/disable synced across Chrome profile
- Skips `pre` / `code` blocks to avoid breaking code samples
- Shadow-DOM and ProseMirror/Quill editor support

### How to use

1. Install the extension and open the toolbar popup.
2. Turn **Enable** on.
3. Choose **All websites** or **AI chat sites only**.
4. Type or read mixed Persian + English text — fixes apply automatically.

### Permissions

- **Storage:** saves your on/off and site-scope settings (Chrome sync).
- **Runs on websites:** required to fix text on pages you visit; you control scope in settings.

## Category

`Productivity` or `Accessibility`

## Single purpose description (required)

This extension has one purpose: **improve visual reading order of mixed right-to-left and left-to-right text** on web pages by inserting Unicode bidirectional formatting characters and applying limited CSS direction hints.

## Permission justification (host access / all URLs)

The extension must access page DOM text to fix mixed-script rendering on user-opened sites. Users can restrict execution to **AI chat site presets** or exclude hosts. No data is sent to the developer’s servers.
